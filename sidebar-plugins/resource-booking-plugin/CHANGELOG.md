# Changelog

## 2026-08-30

- 新增预约表选择：配置页可明确选择哪张数据表作为预约记录表。
- 新增保存配置按钮：字段映射先作为草稿编辑，点击保存后才正式用于预约读取和写入。
- 固定预约写入表：预约、冲突检查、预约状态刷新都使用已保存的预约表，不再跟随当前打开的数据表变化。
- 优化配置页文案：配置页说明改为“预约表字段配置”，强调字段来自预约记录表，资源来自资源配置表。
- 简化按小时预约页：隐藏可用开始、可用结束、时间粒度、占用时长等配置项，只保留预约日期。
- 删除占用时长输入：按小时预约时，每个时间格的长度直接等于资源配置表中的时间粒度；需要更长时间时可选择多个连续时间格。
- 修复资源下拉框：只要存在资源配置表，就严格按“是否启用”筛选资源；全部停用时不再回退显示预约表里的旧选项。
