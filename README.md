# lark-tools

飞书 / Lark 插件与工具集合。

## Directory

- `sidebar-plugins/`: 边栏插件
- `field-shortcuts/`: 字段捷径
- `node-shortcuts/`: 节点捷径
- `view-plugins/`: 视图插件
- `app-plugins/`: 应用插件

当前已包含：

- `sidebar-plugins/resource-booking-plugin`: 通用资源预约边栏插件
